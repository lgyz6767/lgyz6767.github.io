The tweak requires LiquidAss ≥ 0.1.1 (iOS 15, rootless). It re-adds the old “custom class” workflow: add rules with scope (SpringBoard / Global / per-app), target & parent class names, liquid-glass parameters, button animation and much more — right from the settings app.

Tweaks

LiquidAssCustom 0.1.0

Package: com.lgyz.pro · Section: Tweaks · Arch: iphoneos-arm64

  • Custom liquid-glass rules: scope, target / parent / grandparent classes, glass parameters, strong background clear
  • LG button with menu — sample class (with child/parent class picker), manage rules, menu customization, drag & rotate
  • Auto mask color & corner radius, adaptive colors, multi-language (EN / ZH / VN)
  • Free-rotate tweak & upside-down rotation support for iPhone 7 (iOS 15.8.x)

Installation

1. Open Sileo → Sources → Add → paste lgyz6767.github.io.
2. Install LiquidAssCustom.
3. Open Settings → LiquidAssCustom → add a rule (class names can be picked right from the screen via the LG button).
4. Respring / restart SpringBoard.
